# 刘雅轩的个人学术主页

这是一个面向 GitHub Pages 的中英双语学术主页与博客框架。网站包括首页、研究、数据与代码、CV 和博客。

## 最快的使用方式

1. 在 GitHub 创建公开仓库 `LiuYaxuan33.github.io`。
2. 上传本框架的全部文件。
3. 打开仓库的 **Settings → Pages**。
4. 在 **Build and deployment → Source** 中选择 **GitHub Actions**。
5. 打开仓库的 **Actions** 页面，等待 `Deploy GitHub Pages` 变成绿色完成状态。
6. 访问 `https://liuyaxuan33.github.io`。

网站内容的详细填充方法见 [CONTENT_GUIDE.md](CONTENT_GUIDE.md)。
